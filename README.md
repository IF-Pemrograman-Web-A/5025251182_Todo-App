Deskripsi : Web Todo List sebagai Study Planner mahasiswa dengan fitur CRUD Task, pilihan kategori Personal & Shared, deadline, dan Dark Mode dengan ungu as base warna website. Pengembangan Todo App menjadi Progressive Web App (PWA) dengan fitur Web App Manifest, instalasi aplikasi (Install App), precaching dan caching menggunakan Service Worker, serta halaman offline sebagai fallback ketika tidak ada koneksi internet.
(HTML, CSS, JavaScript, PHP, dan MySQL)
